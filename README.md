## Preguntas y respuestas

### 1. ¿Cómo se declaran las variables?
Las variables se declaran indicando primero su tipo de dato (`int`, `float`, `double`, `char`, `string`, etc.) y después su nombre.

Ejemplo:
```cpp
int edad = 18;
```

### 2. ¿Cómo se delimitan los bloques de código?
Los bloques de código se delimitan mediante llaves `{ }`, que indican dónde empieza y termina un bloque.

### 3. ¿Qué cambia en la sintaxis respecto a Python?
En C++ es obligatorio declarar el tipo de las variables, utilizar punto y coma (`;`) al final de las instrucciones y llaves `{ }` para delimitar bloques. En Python se utilizan las tabulaciones o espacios para organizar el código.

### 4. ¿Qué parte de la lógica se mantiene igual?
Se mantienen los conceptos básicos de programación, como las variables, las condiciones (`if`), los bucles (`for` y `while`) y las operaciones. La lógica de los algoritmos es prácticamente la misma, aunque cambia la forma de escribirlos.
